# Code Quality Standards

## JavaScript (ESM & Vanilla)

- [ ] Use meaningful, camelCase variable and function names.
- [ ] Implement early returns for error handling.
- [ ] Minimize global variables; use modules.
- [ ] Prefer `const` and `let` over `var`.
- [ ] Write small, single-responsibility functions.

## HTML/CSS

- [ ] Use BEM or similar naming conventions for CSS classes.
- [ ] Validate HTML with W3C validator.
- [ ] Maintain consistent indentation (e.g., 2 or 4 spaces).
- [ ] Comment complex logic or non-obvious workarounds.

## Node.js/Backend

- [ ] Implement robust error handling with `try-catch` blocks.
- [ ] Use environment variables for configuration.
- [ ] Sanitize and validate all user inputs.
- [ ] Log errors and important system events.
- [ ] Maintain a clean and logical project structure.
