# Responsive Design Standards

## Viewport Management

- [ ] Use `<meta name="viewport" content="width=device-width, initial-scale=1">`.
- [ ] Implement mobile-first media queries (`min-width`).
- [ ] Use relative units (`rem`, `em`, `%`, `vw`, `vh`) over fixed units (`px`).

## Layout Patterns

- [ ] Leverage CSS Grid and Flexbox for adaptive layouts.
- [ ] Define logical breakpoints (e.g., 600px, 900px, 1200px) based on content.
- [ ] Ensure tap targets (buttons, links) are at least 44x44 CSS pixels.
- [ ] Prevent horizontal overflow on small screens.

## Typography

- [ ] Use fluid typography (`clamp()`) for scalable text.
- [ ] Ensure line height is at least 1.5 for body text.
- [ ] Adjust font sizes and letter spacing for readability across devices.
