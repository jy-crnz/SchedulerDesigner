# Web App Quality Standards

This skill provides expert guidance and actionable checklists to ensure your web applications meet modern standards for performance, accessibility, responsiveness, and code maintainability.

## Quick Start

When you need to improve a specific aspect of your project, refer to the corresponding reference file:

- **[Performance Optimization](references/performance.md)**: Checklists for images, assets, and runtime performance.
- **[Accessibility (A11y)](references/accessibility.md)**: Standards for semantic HTML, keyboard navigation, and ARIA.
- **[Responsive Design](references/responsive-design.md)**: Patterns for mobile-first development and flexible layouts.
- **[Code Quality](references/code-quality.md)**: Best practices for JS, HTML, CSS, and Node.js.

## Workflow: Quality Audit

If you are starting a new feature or auditing an existing project, follow this workflow:

1. **Research & Audit**:
   - Identify the target area (e.g., "The homepage is slow").
   - Review the current implementation against the relevant reference file.
2. **Strategy**:
   - Propose a set of surgical changes based on the gaps identified.
   - Prioritize high-impact, low-effort improvements (e.g., adding `alt` tags before refactoring CSS).
3. **Execution**:
   - Apply the changes incrementally.
   - Use automated tools (e.g., Lighthouse, AXE) if available to validate improvements.

## Usage Examples

- "Audit my `index.html` for accessibility."
- "My scripts are slow, how can I optimize them?"
- "Make the schedule generator responsive for mobile devices."
- "Review my `server.js` for code quality and error handling."
